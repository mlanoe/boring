## How to sign

Signing is done by adding your name to [`CLA-signatories.md`](CLA-signatories.md) as part of your Pull Request.
Add a line in the following format:

```
| Your Name | your@email.com | YYYY-MM-DD | GitHub: @your-handle |
```

A GitHub Actions bot will automatically check that a signatory entry is present before your PR can be merged.

> If you are contributing on behalf of a company, please open an issue first so we can arrange a Corporate CLA.
